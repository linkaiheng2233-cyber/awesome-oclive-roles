# awesome-oclive-roles

Oclive **角色包索引仓库**（`roles.json`）。

本仓库只收录 **条目与镜像链接**，不强制托管角色包文件本体；同一版本支持多个镜像（GitHub / 对象存储 / 网盘等），由客户端在安装前进行 **SHA-256 校验**。

## roles.json

- 文件名固定：`roles.json`
- 索引规范（v1）：见 `oclivenewnew` 仓库文档 `creator-docs/role-pack/ROLE_MARKET_INDEX_V1.md`
  - 建议链接：`https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/creator-docs/role-pack/ROLE_MARKET_INDEX_V1.md`

默认 raw 地址（客户端可直接拉取）：

- `https://raw.githubusercontent.com/linkaiheng2233-cyber/awesome-oclive-roles/main/roles.json`
