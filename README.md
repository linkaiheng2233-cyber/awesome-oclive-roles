# OCLive 角色包目录

供 A.I.Live / OCLive 用户与接入方发现角色包的公开索引。角色包写人设与素材，运行角色的能力由所选 Host 提供。

A public discovery index for OCLive role packs, with source/download links and package-integrity metadata.

## 使用入口

- **查看目录**：[roles.json](roles.json)。条目包含版本、兼容声明、下载位置与 SHA-256 声明。
- **运行角色**：[A.I.Live 主仓库](https://github.com/linkaiheng2233-cyber/oclivenewnew) · [用户手册](https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/creator-docs/getting-started/USER_MANUAL.md)。
- **创作或转换角色包**：[角色包编写器](https://github.com/linkaiheng2233-cyber/oclive-pack-editor)。
- **提交条目**：[CONTRIBUTING.md](CONTRIBUTING.md)。

## 索引与包本体

本仓库维护条目与镜像链接，不要求把角色包文件提交到本仓。下载包的来源、完整性、素材许可和目标 Host 的支持范围需要分别核对；索引中的最低版本声明不等于所有发行版都已验收。

接入方可读取[原始 JSON](https://raw.githubusercontent.com/linkaiheng2233-cyber/awesome-oclive-roles/main/roles.json)。本仓保留对象包裹 `roles` 数组的历史结构；主仓的[社区索引说明](https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/creator-docs/role-pack/ROLE_PACK_INDEX.md)描述数组形式，两者不能按同一个输入格式直接互换。接入时请核对实际消费者；角色内容边界见[角色包说明](https://github.com/linkaiheng2233-cyber/oclivenewnew/blob/main/handoff/ROLE_PACK_BOUNDARY.md)。

目录错误与建议请提交 [Issue](https://github.com/linkaiheng2233-cyber/awesome-oclive-roles/issues)。请勿在公开反馈中附带聊天记录、个人身份资料或 API Key。
